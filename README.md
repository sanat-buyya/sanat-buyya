**Passenger-to-passenger travel coordination platform**

A full-stack application built around passenger listings, transaction workflows, and user communication.

- Secure authentication and role-based workflows
- Passenger and booking information management
- Payment integration and transaction tracking
- Email notifications and administrative controls

**Stack:** Java · Spring Boot · Hibernate · MySQL · React

**Inventory and order management system**

A full-stack application focused on inventory accuracy and reliable order processing.

- Transaction-safe stock reservation
- React frontend with a Spring Boot and PostgreSQL backend

**Stack:** Java · Spring Boot · PostgreSQL · React · TypeScript

### 03 — RITS Billing Suite

**Business billing and management application**
